# Yolinta_Website
My first website with a Main page, About page, Interest page, and Goals page.
Project Title: The title of the website is called Yolinta's Spectacle.
Description: The main purpose of the website is to release my own personal website and provide to various jobs the website that I've been working on. This is my very first fully worked on project with the all the recent coding skills that I've learned throughout the past 2 years. As I continue to learn through HTML, CSS, and JavaScript, I hope to improve this project to become a fully functioning website! Throughout the weeks while working on this project, there has been several problems that occurred. For starters, it was difficult to create a header as well as a footer. The specific difficulty was to separate the main header (Main title of the webpage called Yolinta's Spectacle) from the sub headers that is also in the header. The same can be said about the elements in the footer. The Main difficulty of the project was to ensure the JavaScript part of the project was working for the Light/Dark mode aspect of the code was working. As well as the dropdown menu. My motivation was to test my coding skills on what I've learned so far. Throughout the process, I could do a deeper dive into JavaScript to further my development.
Features: The project has simple, basic features. Nothing too ground-breaking but added a Light/Dark mode and a dropdown menu. The dropdown menu is for the tablet/mobile version.
How To Use: The project for now is very simple. If you would like to checkout the Dark version of the site. It's located in the footer of each page selected.
Technologies: There isn't any technologies used in the site so far.
Collaborators: There isn't any collaborators used in this project so far.
